# 🎮 Simon Game

A browser-based memory game inspired by the classic Simon toy. Watch the colour pattern, repeat it, and see how far you can go!

## Tech Used

- HTML
- CSS
- JavaScript

## Features

- Level counter and high score tracking.
- Difficulty selector -> Easy / Medium / Hard
- Play with mouse clicks or keyboard.

## How to Play

1. Click **Start Game**.
2. Watch the pattern of flashing colours.
3. Repeat the pattern in the same order.
4. Each round adds one more step to the pattern.
5. One wrong move ends the game.

## Controls

-- Mouse click : Press a colour pad 
-- Keys `1`–`4` : Press the matching pad 
-- Arrow keys : Press the matching pad
